# local_lms_dashboard_builder

**LMS Dashboard Builder (Core Engine)** for Moodle 5.2+.

## Overview
`local_lms_dashboard_builder` is a local plugin providing core dashboard definition management, query registry, filters, widgets configuration, and secure data services.

## Requirements
- Moodle 5.2.0 or later (Moodle build `2026042000`)
- PHP 8.3 or PHP 8.4 (64-bit)

## Installation
Clone or copy this directory into your Moodle installation at:
```
local/lms_dashboard_builder
```
Then visit Site Administration > Notifications to complete database installation.
